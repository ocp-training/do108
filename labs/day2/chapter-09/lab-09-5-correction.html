CorrectionWorkshop 9.5 — Gate planner goes live

Open the student lab. Replace userN / ${U} with your account. Values such as node names and ClusterIPs differ on every cluster.

Done when

An empty project can be rebuilt from ~/do108/day2/gateplan/ alone. oc get all -l app.kubernetes.io/part-of=gateplan lists the stack.

Using the console

  1. Create userN-gateplan. Import YAML for Deployment + Service + Route (httpd-24, 2 replicas, part-of=gateplan). Open the route.

  2. Delete the project from Home → Projects. Recreate the project and Import YAML again — same URL shape, new objects.

Using the CLI

[you@laptop ~]$ oc new-project ${U}-gateplan [you@laptop ~]$ oc create deployment gateplan --image=registry.access.redhat.com/ubi9/httpd-24:latest --replicas=2 --port=8080 [you@laptop ~]$ oc label deployment gateplan app.kubernetes.io/part-of=gateplan [you@laptop ~]$ oc expose deployment/gateplan --port=8080 --target-port=8080 [you@laptop ~]$ oc expose service/gateplan [you@laptop ~]$ oc get deploy,svc,route -o yaml > ~/do108/day2/gateplan/all.yaml # strip status/uid/resourceVersion before treating it as source [you@laptop ~]$ oc delete project ${U}-gateplan [you@laptop ~]$ oc new-project ${U}-gateplan [you@laptop ~]$ oc apply -f ~/do108/day2/gateplan/ [you@laptop ~]$ oc get all -l app.kubernetes.io/part-of=gateplan
