A Multiple choice

Concept A container on OpenShift is

A container is a process isolated by kernel namespaces and limited by cgroups — not a small virtual machine.

Concept oc apply prints created. That means

The object is recorded in etcd. Controllers converge afterwards. created is not Running.

Concept A Route

A Route is an OpenShift object on Kubernetes extension points. kubectl works on OpenShift; a Route means nothing to plain Kubernetes.

Concept You delete a pod that a Deployment owns. What happens?

The ReplicaSet still wants n matching pods, so it creates a replacement. To stop the workload, change the Deployment (or delete it).

YAML A Deployment is rejected on create. Check first

spec.selector.matchLabels and spec.template.metadata.labels must agree. If they do not, the API refuses the object.

YAML In a Service, port and targetPort

port is what clients connect to. targetPort is where traffic is delivered inside the container. They are often the same number, which hides the difference.

YAML A Job with restartPolicy: Always

A Job must complete. Always is rejected. Use OnFailure or Never.

Components The control plane includes

API server, etcd, scheduler and controllers. kubelet and CRI-O run on workers (and on a one-node training cluster they share the machine).

Components The object you write and change is the

You write the Deployment. It owns the ReplicaSet. The ReplicaSet owns the pods. Never edit the ReplicaSet.

Components OpenShift’s container runtime is

CRI-O. Images are OCI; an image built elsewhere still runs here.

Access A browser gets HTTP 503 from a Route hostname. First look at

The wildcard DNS still reaches HAProxy. 503 means the router found nothing to send to: no Route, or a Route whose Service has no endpoints. Check Route → Service → endpoints.

Access A ClusterIP Service is reachable from

ClusterIP is internal. Your laptop is not on the pod or service network. Publish HTTP with a Route.

Networking You must never put a pod IP in a ConfigMap because

Pod IPs are not stable. Reschedule, scale or roll and the address changes. Use the Service DNS name (fids-api in the same project).

Networking oc get endpoints fids-api shows <none>. That is

The Service selector matches no ready pod — wrong labels, or no pod is Ready. Empty endpoints is the complete diagnosis for “the service returns 503”.
